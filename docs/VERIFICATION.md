# 検証状況

初回公開日：2026-09-22。

## 今回の公開版

Windows、PowerShell 7.6.5、Android Studio付属のJBR 21.0.10、Android SDK Platform 36、Build Tools 36.0.0で確認しました。

```powershell
pwsh -NoProfile -File .\tests\build.ps1
```

| 確認 | 結果 |
| --- | --- |
| アプリAPKのビルド | 成功 |
| InstrumentationテストAPKのビルド | 成功 |
| 両APKの署名検証 | `apksigner verify`成功。v2・v3署名を検証 |
| 署名鍵 | 両APKを同じ新規ローカル開発用鍵で作成 |
| ゲーム・テストのJavaソース | 実装変更なし。改行をLFに統一し、行末・ファイル末尾の空白のみ整理 |
| Gitの公開対象 | ソース・文書・MITライセンスなど21ファイル。生成したAPK、鍵、ビルド中間物は除外 |

コンパイル時にはJava 8のsource/target指定と非推奨APIについて警告が出ますが、ビルドは終了コード0で完了しました。テストAPKがビルドできたことと、実機テストに合格したことは別です。

今回生成したAPKのSHA-256：

- アプリ：`0E53BF6CC47503CE6B0D52EF50DD926F41F3F4A63D9D088205B16BA460F9A097`
- テスト：`D941239E18FBA036A611DC142823C58AB2FC73A36DBA2FE3BB4C298B38E81AD9`

各自で生成する開発用鍵やビルド時刻によって、再ビルド時のAPKハッシュは変わります。

2026-09-22にADBの接続端末一覧を確認しましたが、端末は接続されていませんでした。今回の公開版の実機テスト、装着時の操作感、スピーカー音の確認は未実施です。
